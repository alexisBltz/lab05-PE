# Laboratorio 05 Aplicaciones Multiplataforma

## Análisis de la guía

Se revisaron las cuatro páginas de la guía oficial. El proyecto debe abordar un problema con proyección social, mantener relación con el diseño anterior, usar un framework multiplataforma y mostrar funcionalidades basadas en el árbol de problemas. El informe debe contener carátula, resumen, tres índices, propósito, requisitos funcionales completos y pendientes, requisitos no funcionales, tareas asignadas por integrante, proceso por módulos, interfaces, anexos con GitHub y ejecutable o video y referencias.

## Decisiones de implementación

Se continúa UniBudget con React Native y Expo SDK 58. Se conserva el diseño base del Laboratorio 04 y se completa el funcionamiento. El aporte social consiste en acceso gratuito a registro de gastos, presupuesto y educación financiera breve, sin exigir una cuenta. Se incorporan una meta de ahorro y seguimiento de lecturas educativas sustentadas en materiales públicos de la SBS. No se afirma haber realizado validación con una comunidad ni se inventan entrevistas.

| Criterio oficial | Desarrollo | Comprobación |
